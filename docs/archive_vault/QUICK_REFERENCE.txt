────────────────────────────────────────────────────────────────────────────
TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

"No active VMs"           → Boot a VM via curl or test_phase4_simple.py
"Connection failed"       → Restart backend, check port 6080
"Docker error"            → Start Docker Desktop
"Build error"             → cd frontend && npm run build
"terser not found"        → npm install --save-dev terser
"Cannot resolve module"   → Already fixed in current build
