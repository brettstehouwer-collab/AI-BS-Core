## 🚀 Standalone Distribution & Packaging Guidance

1. **Web Deployment (PWA / Live Cloud):**
   - Live URL: `https://ai-bs-dashboard.web.app`
   - Command: `powershell -ExecutionPolicy Bypass -Command "npm run build; firebase deploy --only hosting --non-interactive"` from `C:\AI-BS\frontend`.

2. **Local Desktop Workstation (BS-Studio / Windows 11):**
   - Portable binary: `AI-BS.exe`
   - Master Launch Script: `C:\AI-BS\Launch_AI_BS.bat` boots FastAPI (8080), Ollama (11434), ChromaDB (8001), and Vite (5173).

3. **Memory Bank Auto-Start Configuration:**
   - The Infinite Learning Loop daemon runs under `daemon_manager.py` or can be toggled via `MemoryBankSupervisor.jsx` in the UI.
   - Persistence target: `D:\AI-BS_Master_Memory\master_memory_dump.json`.
