## Existing safeguards worth retaining

- Process-local explicit activation fails closed for missing/unknown values. Sending primitives and major send endpoints have disabled guards.
- Administrative router access is protected; TextBee inbound webhooks require configured HMAC verification when admin credentials are absent. Reviewed access helper verifies the body signature but has no timestamp/replay window; preserve signature verification and add replay protection rather than relying only on downstream dedupe.
- Reply forwarding checks personal exclusions and an exact unique roster match, and blocks when privacy checks are unavailable. Do not weaken this while consolidating sends.
- TextBee batch staging already normalizes/deduplicates phones and consults personal exclusions; preserve those protections while correcting failed-response accounting and sharing the policy.

4. Only after these checks pass, arrange separately authorized single-recipient delivery verification to an approved test destination. Bulk sending requires a reviewed audience, content, sender identity and limits. This audit grants no sending authorization.
