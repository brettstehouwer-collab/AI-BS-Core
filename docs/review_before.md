* Maps abstract functional tags to concrete codebase implementations.

* Compares incoming feature requests or existing module implementations against the current Capability Matrix.  
* Evaluates three specific dimensions:

  * Fine-Tuning Opportunities: Scans for blocking synchronous file I/O or missing async handlers inside high-frequency event loops.

#### IV. Patch Generation & Sandbox Validation (PatchEngine)

* Generates standard .patch unified diffs.  
* Runs isolated dry-run unit tests in a subprocess before applying patches to production code.

        \# 3\. Check Breaking API Signatures against Symbol Graph  
        existing\_symbols \= self.symbol\_graph.get(file\_path, {}).get("functions", {})  
        current\_functions \= {  
            node.name: node for node in ast.walk(tree) if isinstance(node, ast.FunctionDef)

        for func\_name, old\_meta in existing\_symbols.items():  
            if func\_name in current\_functions:  
                new\_node \= current\_functions\[func\_name\]  
                old\_args\_count \= old\_meta.get("arg\_count", 0\)  
                new\_args\_count \= len(new\_node.args.args)

                \# Check if required positional arguments were altered without default values

## System Architecture: Isolated Subprocess Sandbox Runner

The Subprocess Sandbox Runner executes generated code patches in an isolated, ephemeral workspace. It prevents unverified code from altering the host system, writing to host files, or running unauthorized background processes.

### Security & Runtime Isolation Constraints

| Isolation Boundary | Constraint Mechanism | Technical Purpose |
| :---- | :---- | :---- |
| Filesystem | Temporary isolated directory (tempfile.TemporaryDirectory) | Prevents write operations from modifying the real codebase or root system files. |
| Environment Variable Stripping | Restricts os.environ payload passed to subprocess | Prevents leaking system keys, credentials, or host paths to untrusted execution tasks. |
| Execution Timeout | Hard timeout limit via subprocess.run(timeout=...) | Terminates infinite loops or blocking calls automatically. |
| Network Boundaries | Runs with zero network proxy bindings or isolated socket flags | Prevents untrusted scripts from opening outbound internet connections. |
| Process Lifecycle | Ephemeral worker process | Worker subprocess terminates immediately after execution; memory and handles are freed. |

### Execution Flow

1  
Sandbox Provisioning  
Prevents permanent disk modification  
Generates a clean temporary directory on disk. Copies target files into this workspace while keeping the real repository untouched.  
2  
Patch Application  
Rejects invalid unified diffs immediately  
Applies the candidate patch (.patch or modified code string) directly to the target files inside the temporary directory.  
3  
Execution in Reduced Environment  
Isolated subprocess spawning  
Launches a dedicated Python subprocess with its current working directory (cwd) pointed to the temporary folder and a stripped environment map.  
4  
Diagnostic Capture  
Runs unit tests and static checks  
Captures standard output (stdout), standard error (stderr), exit code, and execution runtime.  
5  
Automated Sandbox Destruction  
Ensures zero artifact accumulation  
Deletes the temporary directory and all generated artifacts regardless of whether execution passed, failed, or timed out.

import sys  
import time  
import shutil  
import subprocess  
import tempfile  
from dataclasses import dataclass  
from pathlib import Path  
from typing import Optional, Dict

@dataclass  
class SandboxResult:  
    status: str  \# "PASSED", "FAILED", "TIMEOUT", "EXECUTION\_ERROR"  
    exit\_code: int  
    execution\_time\_sec: float  
    stdout: str  
    stderr: str  
    patch\_applied: bool

class SubprocessSandboxRunner:  
    def \_\_init\_\_(self, default\_timeout\_sec: float \= 10.0):  
        self.default\_timeout\_sec \= default\_timeout\_sec

    def execute\_in\_sandbox(  
        self,  
        original\_file\_path: str,  
        modified\_code: str,  
        test\_script\_code: Optional\[str\] \= None,  
        timeout\_sec: Optional\[float\] \= None  
    ) \-\> SandboxResult:  
        timeout \= timeout\_sec or self.default\_timeout\_sec  
        start\_time \= time.perf\_counter()

        \# 1\. Create temporary isolated directory  
        with tempfile.TemporaryDirectory(prefix="ide\_sandbox\_") as temp\_dir:  
            temp\_path \= Path(temp\_dir)  
            target\_name \= Path(original\_file\_path).name  
            sandbox\_target\_file \= temp\_path / target\_name

            \# 2\. Write modified code into sandbox workspace  
            try:  
                sandbox\_target\_file.write\_text(modified\_code, encoding="utf-8")  
            except Exception as e:  
                return SandboxResult(  
                    status="EXECUTION\_ERROR",  
                    exit\_code=-1,  
                    execution\_time\_sec=0.0,  
                    stdout="",  
                    stderr=f"Failed to write candidate code to sandbox: {str(e)}",  
                    patch\_applied=False  
                )

            \# 3\. Create entrypoint execution script  
            entrypoint\_script \= temp\_path / "\_runner\_entrypoint.py"  
            if test\_script\_code:  
                entrypoint\_script.write\_text(test\_script\_code, encoding="utf-8")  
            else:  
                \# Default sanity check: compile and run simple import test  
                entrypoint\_script.write\_text(  
                    f"import sys\\n"  
                    f"sys.path.insert(0, '.');\\n"  
                    f"import {sandbox\_target\_file.stem}\\n"  
                    f"print('Compilation and import successful.')\\n",  
                    encoding="utf-8"  
                )

            \# 4\. Strip environment variables for isolated execution  
            sanitized\_env: Dict\[str, str\] \= {  
                "PATH": os.environ.get("PATH", ""),  
                "PYTHONPATH": str(temp\_path),  
                "SYSTEMROOT": os.environ.get("SYSTEMROOT", ""),  \# Required for Windows process startup  
                "PYTHONUNBUFFERED": "1"  
            }

            \# 5\. Launch isolated subprocess  
            try:  
                process \= subprocess.run(  
                    \[sys.executable, str(entrypoint\_script)\],  
                    cwd=str(temp\_path),  
                    env=sanitized\_env,  
                    capture\_output=True,  
                    text=True,  
                    timeout=timeout  
                )

                elapsed\_time \= time.perf\_counter() \- start\_time  
                status \= "PASSED" if process.returncode \== 0 else "FAILED"

                return SandboxResult(  
                    status=status,  
                    exit\_code=process.returncode,  
                    execution\_time\_sec=round(elapsed\_time, 4),  
                    stdout=process.stdout,  
                    stderr=process.stderr,  
                    patch\_applied=True  
                )

            except subprocess.TimeoutExpired as e:  
                elapsed\_time \= time.perf\_counter() \- start\_time  
                return SandboxResult(  
                    status="TIMEOUT",  
                    exit\_code=-1,  
                    execution\_time\_sec=round(elapsed\_time, 4),  
                    stdout=e.stdout.decode("utf-8") if e.stdout else "",

                    patch\_applied=True  
                )

            except Exception as e:  
                elapsed\_time \= time.perf\_counter() \- start\_time  
                return SandboxResult(  
                    status="EXECUTION\_ERROR",  
                    exit\_code=-1,  
                    execution\_time\_sec=round(elapsed\_time, 4),  
                    stdout="",  
                    stderr=f"Subprocess runner error: {str(e)}",  
                    patch\_applied=False  
                )

## Orchestrator Architecture: Patch Promoter Engine

The Patch Promoter acts as the central orchestration gatekeeper in the self-healing workflow. It coordinates the Implication Risk Evaluator, the Subprocess Sandbox Runner, and the active codebase/Git repository.  
Code changes are never applied directly to production disk files. A patch must sequentially pass the static risk index check and the isolated sandbox test execution before being written to disk or committed to Git.

### End-to-End Promotion Sequence

1  
Risk Index Assessment  
Gate 1: Static Risk & Dependency Evaluation  
Passes the candidate code diff to the ImplicationRiskEvaluator. Evaluates AST signature stability, system call privileges, and dependency radius in symbol\_graph.json. If the Risk Index reaches or exceeds 30, promotion halts immediately.  
2  
Sandbox Validation  
Gate 2: Isolated Compilation & Execution  
Spawns an isolated SubprocessSandboxRunner instance in a temporary workspace directory. Executes target unit test suites, verifies clean compilation, and asserts exit code 0 under strict resource limits.  
3  
Production File Mutation & Git Commit  
Gate 3: Host File System & Version Control  
Writes the verified code patch to the host workspace target path. Optionally creates a clean Git commit on the active branch with an embedded audit metadata payload.  
4  
Symbol Graph Refresh  
Gate 4: System State Synchronization  
Triggers an incremental re-index of symbol\_graph.json to reflect updated AST definitions and updated module dependency paths.

class PromotionResult:

class PatchPromoter:  
    def \_\_init\_\_(  
        self,

        self,  
        rel\_target\_path: str,  
        new\_code\_content: str,  
        test\_script\_code: Optional\[str\] \= None  
    ) \-\> PromotionResult:  
        full\_target\_path \= self.workspace\_root / rel\_target\_path  
        audit\_dir \= self.workspace\_root / ".ide\_audit\_logs"  
        audit\_dir.mkdir(exist\_ok=True)  
        audit\_file \= audit\_dir / f"promotion\_{Path(rel\_target\_path).stem}.json"

        \# Read current code baseline for evaluation  
        current\_code \= ""  
        if full\_target\_path.exists():  
            current\_code \= full\_target\_path.read\_text(encoding="utf-8")

        \# \-------------------------------------------------------------  
        \# STEP 1: Implication Risk Evaluation

            res \= PromotionResult(  
                status="BLOCKED\_RISK",  
                target\_file=rel\_target\_path,  
                risk\_report=asdict(risk\_report),  
                sandbox\_result={},  
                git\_commit\_hash=None,  
                audit\_log\_path=str(audit\_file)  
            )  
            self.\_write\_audit\_log(audit\_file, res)  
            return res

        \# \-------------------------------------------------------------  
        \# STEP 2: Subprocess Sandbox Validation  
        \# \-------------------------------------------------------------  
        sandbox\_res: SandboxResult \= self.sandbox\_runner.execute\_in\_sandbox(  
            original\_file\_path=str(full\_target\_path),  
            modified\_code=new\_code\_content,  
            test\_script\_code=test\_script\_code  
        )

            res \= PromotionResult(  
                status="BLOCKED\_SANDBOX",  
                target\_file=rel\_target\_path,  
                risk\_report=asdict(risk\_report),  
                sandbox\_result=asdict(sandbox\_res),  
                git\_commit\_hash=None,  
                audit\_log\_path=str(audit\_file)  
            )  
            self.\_write\_audit\_log(audit\_file, res)  
            return res

        \# \-------------------------------------------------------------  
        \# STEP 3: Host File System Write  
        \# \-------------------------------------------------------------  
        try:  
            full\_target\_path.parent.mkdir(parents=True, exist\_ok=True)  
            full\_target\_path.write\_text(new\_code\_content, encoding="utf-8")  
        except Exception as e:

                status="FILE\_WRITE\_ERROR",  
                target\_file=rel\_target\_path,  
                risk\_report=asdict(risk\_report),  
                sandbox\_result=asdict(sandbox\_res),  
                git\_commit\_hash=None,  
                audit\_log\_path=str(audit\_file)  
            )  
            self.\_write\_audit\_log(audit\_file, res)  
            return res

        commit\_hash \= None

            status="PROMOTED",  
            target\_file=rel\_target\_path,  
            risk\_report=asdict(risk\_report),  
            sandbox\_result=asdict(sandbox\_res),  
            git\_commit\_hash=commit\_hash,  
            audit\_log\_path=str(audit\_file)  
        )  
        self.\_write\_audit\_log(audit\_file, res)  
        return res

                return json.loads(self.symbol\_graph\_path.read\_text(encoding="utf-8"))  
            except Exception:  
                return {}  
        return {}

    def \_commit\_to\_git(self, rel\_target\_path: str) \-\> Optional\[str\]:  
        try:  
            \# Stage file  
            subprocess.run(  
                \["git", "add", rel\_target\_path\],  
                cwd=str(self.workspace\_root),  
                check=True,  
                capture\_output=True  
            )  
            \# Commit with automated tag  
            msg \= f"auto(ide): verified patch promotion for {rel\_target\_path}"  
            subprocess.run(  
                \["git", "commit", "-m", msg\],  
                cwd=str(self.workspace\_root),  
                check=True,  
                capture\_output=True

            rev\_parse \= subprocess.run(

                capture\_output=True,  
                text=True  
            )  
            return rev\_parse.stdout.strip()  
        except subprocess.CalledProcessError:

    def \_write\_audit\_log(self, audit\_file: Path, result: PromotionResult):

## System Architecture: Symbol Graph Auto-Updater

The Symbol Graph Auto-Updater maintains an up-to-date index of all code structures across the workspace. Triggered automatically after a patch passes promotion, it re-scans Abstract Syntax Trees (ASTs) to map classes, functions, function signatures, and import relationships across all 30+ system utilities.  
This persistent map (symbol\_graph.json) allows the Implication Risk Evaluator to calculate downstream breaking changes in real time without scanning the entire file system on every check.

### AST Extraction Matrix

| AST Node Type | Extracted Metadata | System Purpose |
| :---- | :---- | :---- |
| ast.FunctionDef / AsyncFunctionDef | Name, argument list, positional count, default value count | Detects parameter removals or missing default values (breaking signature changes). |
| ast.ClassDef | Class name, inherited base classes, methods | Tracks object-oriented relationships and inherited method overrides. |
| ast.Import / ast.ImportFrom | Target module names, imported symbols | Builds direct dependency edges between modules. |
| Inverse Map Calculation | dependents list per file | Maps impact radius when a shared module is modified. |

## Python Symbol Graph Auto-Updater Implementation

The script below performs incremental or full workspace re-indexing and writes the updated symbol map atomically to disk.  
Python  
import ast  
import json  
from pathlib import Path  
from typing import Dict, Any, List, Set, Optional

class SymbolGraphUpdater:  
    def \_\_init\_\_(self, workspace\_root: str, graph\_output\_path: str):  
        self.workspace\_root \= Path(workspace\_root).resolve()  
        self.graph\_output\_path \= Path(graph\_output\_path).resolve()

    def update\_graph(self, target\_files: Optional\[List\[str\]\] \= None) \-\> Dict\[str, Any\]:  
        """  
        Scans workspace Python files, builds/updates symbol metadata,   
        calculates dependency links, and updates symbol\_graph.json.  
        """  
        existing\_graph \= self.\_load\_existing\_graph()

        \# Determine which files to scan  
        if target\_files:  
            files\_to\_scan \= \[self.workspace\_root / f for f in target\_files\]  
        else:  
            files\_to\_scan \= list(self.workspace\_root.rglob("\*.py"))

        \# Parse AST for target files  
        for file\_path in files\_to\_scan:  
            if not file\_path.exists() or not file\_path.is\_file():  
                continue

            \# Ignore virtual environments, git folders, and temp test runners  
            if any(part.startswith((".", "venv", "\_\_pycache\_\_")) for part in file\_path.parts):  
                continue

            rel\_path \= str(file\_path.relative\_to(self.workspace\_root)).replace("\\\\", "/")  
            file\_metadata \= self.\_parse\_file\_ast(file\_path)

            if file\_metadata is not None:  
                existing\_graph\[rel\_path\] \= file\_metadata

        \# Recalculate inverse dependencies across the entire graph  
        self.\_recalculate\_dependents(existing\_graph)

        \# Write graph atomically to disk  
        self.\_save\_graph(existing\_graph)  
        return existing\_graph

    def \_parse\_file\_ast(self, file\_path: Path) \-\> Optional\[Dict\[str, Any\]\]:  
        try:  
            content \= file\_path.read\_text(encoding="utf-8")  
            tree \= ast.parse(content)  
        except (SyntaxError, UnicodeDecodeError):  
            \# Skip invalid syntax or unreadable binary files  
            return None

        functions: Dict\[str, Dict\[str, Any\]\] \= {}  
        classes: Dict\[str, List\[str\]\] \= {}  
        imports: Set\[str\] \= set()

        for node in ast.walk(tree):  
            \# Extract Functions  
            if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)):  
                arg\_names \= \[arg.arg for arg in node.args.args\]  
                defaults\_count \= len(node.args.defaults)  
                functions\[node.name\] \= {  
                    "args": arg\_names,  
                    "arg\_count": len(arg\_names),  
                    "defaults\_count": defaults\_count,  
                    "required\_args\_count": len(arg\_names) \- defaults\_count,  
                    "is\_async": isinstance(node, ast.AsyncFunctionDef)  
                }

            \# Extract Classes and Method Names  
            elif isinstance(node, ast.ClassDef):  
                method\_names \= \[  
                    subnode.name for subnode in node.body   
                    if isinstance(subnode, (ast.FunctionDef, ast.AsyncFunctionDef))  
                \]  
                classes\[node.name\] \= method\_names

            \# Extract Direct Imports  
            elif isinstance(node, ast.Import):  
                for alias in node.names:  
                    imports.add(alias.name)

            \# Extract From Imports  
            elif isinstance(node, ast.ImportFrom):  
                if node.module:  
                    imports.add(node.module)

        return {  
            "functions": functions,  
            "classes": classes,  
            "imports": sorted(list(imports)),  
            "dependents": \[\]  \# Populated during recalculation step  
        }

    def \_recalculate\_dependents(self, graph: Dict\[str, Any\]) \-\> None:  
        """  
        Maps which files import other files in the graph to calculate downstream impact radius.  
        """  
        \# Clear existing dependents lists  
        for module\_data in graph.values():  
            module\_data\["dependents"\] \= \[\]

        \# Compare imports against known module file paths  
        for target\_file, data in graph.items():  
            for imported\_mod in data.get("imports", \[\]):  
                \# Convert module dot notation to relative file path (e.g., "modules.parsers" \-\> "modules/parsers")  
                expected\_path\_prefix \= imported\_mod.replace(".", "/")

                for file\_key in graph.keys():  
                    if file\_key \!= target\_file and file\_key.startswith(expected\_path\_prefix):  
                        if target\_file not in graph\[file\_key\]\["dependents"\]:  
                            graph\[file\_key\]\["dependents"\].append(target\_file)

    def \_load\_existing\_graph(self) \-\> Dict\[str, Any\]:  
        if self.graph\_output\_path.exists():  
            try:  
                return json.loads(self.graph\_output\_path.read\_text(encoding="utf-8"))  
            except Exception:  
                return {}  
        return {}

    def \_save\_graph(self, graph: Dict\[str, Any\]) \-\> None:  
        self.graph\_output\_path.parent.mkdir(parents=True, exist\_ok=True)  
        \# Write to temporary file first then replace for atomic writing  
        temp\_path \= self.graph\_output\_path.with\_suffix(".tmp")  
        temp\_path.write\_text(json.dumps(graph, indent=2), encoding="utf-8")  
        temp\_path.replace(self.graph\_output\_path)

### 3\. End-to-End Patch Promotion

Executes static evaluation, sandbox unit testing, host file writing, Git committing, and symbol graph re-indexing in a single atomic action:  
Bash  
python ide\_orchestrator.py \--workspace . promote \\  
  \--target "modules/parsers/fdx\_exporter.py" \\  
  \--patch "temp/candidate\_fdx\_patch.py" \\  
  \--test "tests/test\_fdx\_exporter.py"
