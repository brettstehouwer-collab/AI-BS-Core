================================================================================
SIZE CANNOT BE REDUCED (Core Dependencies)
================================================================================

These components are REQUIRED for application functionality and cannot be removed:

1. Electron (172 MB) - Desktop app framework
   - No alternative smaller framework for React + native APIs
   - Chromium is essential for rendering

2. PyTorch CPU (293 MB) - Machine Learning
   - Required for: trainer_daemon, memory embeddings, heuristic generation
   - Alternative: Remove ML features entirely (breaks functionality)
   - Workaround: Use ONNX Runtime only (saves ~200 MB but loses training capability)

3. Brain Backend (60 MB) - Python backend executable
   - Required for: All backend services integrated in Electron
   - Alternative: Keep backend separate, don't bundle (breaks offline functionality)

4. PDF Rendering (24 MB) - Document processing
   - Required for: DocumentsTab, screenplay export as PDF
   - Alternative: Remove PDF export (loses functionality)

5. Scientific libraries (39 MB) - Data analysis & ML
   - Required for: telemetry analysis, mining data processing
   - Alternative: Remove mining/compute monitoring (loses functionality)

================================================================================
FURTHER OPTIMIZATION OPTIONS (Trade-offs)
================================================================================

Option A: ONNX Runtime Only (Save ~250 MB, lose training)
  - Remove torch_cpu.dll, torch_python.dll, libscipy_openblas
  - Use ONNX Runtime for inference only
  - Impact: Trainer daemon disabled, memory embeddings fail
  - New size: ~820 MB

Option B: Separate Backend (Save ~60 MB, reduce offline capability)
  - Don't bundle brain_backend.exe in Electron package
  - Require separate backend installation
  - Impact: App requires external service
  - New size: ~1,011 MB

Option C: Web-only (Save ~170 MB, lose desktop features)
  - Remove Electron, deploy as web app only
  - Use web technologies instead
  - Impact: No native OS integration, must use web hosting
  - New size: ~70 MB web bundle

Option D: Remove PDF Support (Save ~24 MB, lose export)
  - Remove mupdfcpp64.dll
  - Disable PDF rendering in DocumentsTab
  - Impact: No PDF export for screenplays
  - New size: ~1,047 MB

Option E: Minimal Locale Pack (Save ~4 MB, lose language support)
  - Keep only en-US.pak (remove other 9 languages)
  - Impact: UI only works in English
  - New size: ~1,067 MB

RECOMMENDED DEPLOYMENT STRATEGY

Current build is already OPTIMIZED for:
  • Development: 1,071 MB is acceptable for internal tools
  • Distribution: NSIS installer compresses to ~350-400 MB on disk
  • Runtime: Only loads what's used (lazy loading reduces memory)

Best practices moving forward:

1. UPDATE BUILD PROCESS:
   - Run optimize_build.py after every `npm run build`
   - Add to CI/CD pipeline: `npm run build && python optimize_build.py`
   - Git commit only dist/dist-electron (exclude build-output)

2. DISTRIBUTION:
   - Use electron-builder with NSIS compression
   - Installer size: ~300-400 MB (good for auto-update)
   - Portable exe: ~600 MB (good for USB/manual distribution)

3. PERFORMANCE:
   - Initial load: ~2-3s (lazy-loaded tabs)
   - Tab switching: ~500ms (chunks loaded on-demand)
   - Memory footprint: ~400-600 MB (depends on active features)

4. FUTURE IMPROVEMENTS:
