# Implementation Plan: Pure Context-Driven Social Outreach Optimizer (v5.171.0)

Eliminate all hardcoded assumptions of "Stehouwer Publishing", book releases, or reading audiences. Re-architect the Social Optimizer Engine to dynamically extract topic, niche, tone, entities, and call-to-action solely from the user's input text and outbound URLs.

## User Review Required

> [!IMPORTANT]
> **Zero Brand Assumption Guarantee:**
> - `#StehouwerPublishing` will **never** appear unless the user explicitly types "Stehouwer" or "Publishing" in the input text.
> - Call-to-action cues will dynamically reflect the link type (e.g. IMDb profile, YouTube video, Spotify track, GitHub repo, or general direct link), rather than assuming "Book details".
> - All 3 hashtag boxes will adapt their audience titles and tag sets dynamically to the detected topic (Film/Acting, Tech/Engineering, Music/Art, B2B/Business, Personal/Friendship, Memoir, etc.).

## Proposed Changes

### 1. Backend Core Engine (`backend/core/social_optimizer_engine.py`)
- **Expanded Topic & Entity Classifier:**
  - Build comprehensive keyword & context matcher with categories:
    1. `film_acting_theatre`: Film, set, stage, lines, actor, actress, role, IMDb, audition, director, cinema.
    2. `music_audio_performance`: Music, band, concert, guitar, track, album, lyrics, singing, gig.
    3. `personal_friendship_appreciation`: Friend, appreciation, support, kindness, loyal, gratitude, shoutout.
    4. `tech_software_engineering`: Code, software, GPU, AI, python, hardware, developer, system, dev.
    5. `business_commercial_growth`: Sales, revenue, clients, leads, marketing, B2B, enterprise, services.
    6. `memoir_trauma_recovery`: CPTSD, trauma, memoir, autobiography, healing, mental health, resilience.
    7. `creative_writing_literature`: Book, novel, author, chapter, reading, poetry, story.
    8. `general_authentic_life`: Universal fallback for authentic thoughts, mindset, life lessons.
- **Dynamic Contextual Hashtag Synthesizer:**
  - 3-tier matrix generator strictly capped at 3–6 hashtags per box, pulling tags matching the specific detected topic and context.
  - Box 1: Core Outreach (Niche + Specific Context)
  - Box 2: Discovery & Community (Industry Tribe & Peer Communities)
  - Box 3: Algorithmic & Search Mix (Broad Trending Topics & Discovery)
- **Context-Aware Link Callout Engine:**
  - Detect link type from URL domain and surrounding text:
    - IMDb -> `(IMDb profile & link pinned in the first comment 👇)`
    - YouTube/Vimeo -> `(Video link pinned in the first comment 👇)`
    - Music/Spotify -> `(Music link pinned in the first comment 👇)`
    - Book/Amazon -> `(Book link pinned in the first comment 👇)`
    - General URL -> `(Direct link pinned in the first comment 👇)`
- **Dynamic Box Audience Descriptions:**
  - Dynamic box subtitles instead of static "Reader Mix" (e.g., "Industry Peers & Community Groups", "Audience & Discovery Network").
