# Task List: Phase 4 (Inner Module Component Draggability)

This document outlines the proposed implementation plan for adding draggability to components *inside* our existing module panels.

> [!IMPORTANT]
> User review is required on the Open Questions section before we begin execution.

## Goal Description

Currently, the workspace allows module-level dragging and resizing via `react-grid-layout` (e.g., moving entire panels around the screen). **Phase 4** introduces "Inner Module Component Draggability," which will allow users to drag, drop, and reorder specific items *within* or *between* those individual modules (such as tasks, media items, list elements, or sub-components).

## Open Questions

Before proceeding with the code, please clarify the following so I can tailor the drag-and-drop architecture to your exact needs:

1. **Scope of Draggability**: Which specific modules or data types should become draggable first? (e.g., list items in a specific tab, kanban cards, media files, UI widgets?)
2. **Drag Boundaries**: Do you want users to be able to drag items **between** different modules (e.g., dragging an item from a list in Module A and dropping it into Module B), or just reorder items **within** a single module?
3. **Preferred Library**: For nested and complex drag-and-drop (especially with React 18+), libraries like `@dnd-kit/core` or `@hello-pangea/dnd` (a maintained fork of `react-beautiful-dnd`) are standard. Do you have a preference, or should I proceed with `@dnd-kit/core` as the modern standard?

## Proposed Changes

Assuming a general nested drag-and-drop architecture using `@dnd-kit/core`:

### 1. `C:\AI-BS\frontend\package.json`
- **[MODIFY]**: Add `@dnd-kit/core`, `@dnd-kit/sortable`, and `@dnd-kit/utilities` to dependencies.

### 2. Core DND Components
- **[NEW]** `C:\AI-BS\frontend\components\dnd\DraggableItem.jsx`: A wrapper component providing drag refs, listeners, and transform styles for inner items.
- **[NEW]** `C:\AI-BS\frontend\components\dnd\DroppableContainer.jsx`: A wrapper component defining drop zones within our existing modules.

### 3. Module Updates (TBD based on feedback)
- **[MODIFY]** Specific `...Tab.jsx` components will be wrapped in a `DndContext` provider to manage drag state locally without interfering with the parent `react-grid-layout`.
