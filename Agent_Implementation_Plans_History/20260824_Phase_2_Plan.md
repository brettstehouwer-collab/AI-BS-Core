# BS-Studio Mega-Upgrade: Phase 2 Plan

This document outlines the architecture for Phase 2 of the BS-Studio upgrade: **AI Video FX & Node-Based Compositing**. The goal is to elevate the video pipeline to match industry standards (e.g., DaVinci Resolve's Fusion) and add vocal tuning to the audio engine.

## User Review Required

> [!WARNING]
> Node-based compositing introduces a new interaction paradigm. We will use `@xyflow/react` (React Flow) to handle the node graph. Please review the proposed node types and layout below to ensure they match your workflow expectations.

## Proposed Changes

---

### Node-Based Video Compositor

#### [NEW] [CompositorNodes.jsx](file:///C:/AI-BS/frontend/src/components/daw/CompositorNodes.jsx)
We will define custom React Flow nodes representing industry-standard video operations:
- `VideoSourceNode`: Ingests video from the timeline.
- `ColorTransformNode`: Applies LUTs and Gamma curves.
- `BlurNode`: Standard VFX operation.
- `AIRotoscopingNode`: Leverages SAM (Segment Anything Model) to output an alpha mask.
- `AIGenerativeFillNode`: Takes a mask and a prompt to perform video inpainting.
- `MasterOutNode`: Renders the final composite.

#### [NEW] [NodeCompositor.jsx](file:///C:/AI-BS/frontend/src/components/daw/NodeCompositor.jsx)
The main canvas utilizing `@xyflow/react`. It will feature a left sidebar for dragging nodes onto the canvas, the central node graph, and a right sidebar for tweaking the active node's parameters.

#### [MODIFY] [MusicDAWStudioTab.jsx](file:///C:/AI-BS/frontend/src/components/daw/MusicDAWStudioTab.jsx)
Register the new `NODE_COMPOSITOR` view in the top navigation switcher.
