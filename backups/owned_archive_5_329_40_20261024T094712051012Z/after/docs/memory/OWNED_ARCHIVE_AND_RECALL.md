# Owned vault archives and bounded recall

Implemented local source checkpoint: v5.329.40 / plan1.50. The findings below describe the pre-change source; decisions are implemented with the verification limits stated here. This is not a full Phase4/privacy/RAG release claim.

## Observed source

`core/chat_archive.py` stores full JSON plus transcript in existing vault_items/chat_archive_receipts without an owner. `memory_router.py` lists/searches all rows, falls back to a global JSON dump, uses a constant0.92 search score, writes via a global exporter and physically deletes vault rows. `SovereignMemoryVault.get_unified_context` automatically imports unscoped history, lexicon and11-space searches. Its swarm telemetry stores truncated raw prompts/replies and a default98.5 score without measured evidence. ## Locked implementation decisions

- Reuse the existing vault table. On a valid admitted write only, transactionally add nullable owner and default0 is_hidden columns plus a partial owner/id index. Reads never initialize/migrate. Partial/malformed ownership schema fails closed. Missing owner metadata identifies legacy unassigned records, visible only to the explicit local-administrator realm; it does not establish historical authorship or grant a Firebase UID that history.
- All normal vault read/query/write/hide operations receive the existing server-verified principal. The router independently requires existing conversation administrator authorization. Supplied body/header owner/client labels cannot choose a scope. Existing full conversation revision/outbox authority remains intact.
- New archive receipt IDs are internally namespaced by verified owner while retaining the32hex external archive_id and current sqlite_vault receipt fields. Same-owner retries deduplicate; changed content conflicts; two owners can use the same external ID independently. Preserve old receipts and allow only the local-administrator realm to confirm a legacy receipt. Validate payload/size before any schema/file change; independently read back full committed evidence before durable acknowledgement.
- Removing a memory from the active view sets is_hidden rather than deleting content or receipts. Idempotent hide verifies ownership and retains original bytes. Existing legacy JSON/master exports are not overwritten; new owned writes use SQLite without a second global export.
- List/search apply ownership and hidden predicates. Respect the requested collection. Replace fabricated constant similarity with explicitly labeled actual lexical token coverage. Query limits/time/output are bounded; no vector/semantic-quality claim. Legacy operator-only display remains separate from automatic model ingestion.
- Unified model context reads only owned records with new ownership metadata, never automatic unscoped legacy history/lexicon/omni providers. References carry source/id/content-hash/character offsets and unverified labels, are capped6000characters and exclude recognized credential content. No verified principal -> no retrieval. Missing/unavailable storage reports unavailable rather than substituting foreign/global context. Historical source adoption/secret review/real embeddings remain later work.
- Swarm inference telemetry becomes owner-scoped metadata only (model, lengths/hashes, unmeasured evaluation), using the existing personal event store. Preserve old raw telemetry DBs; no new raw-prompt/reply or invented confidence writes.
- Keep archive-first clear. Require the receipt owner and compare it to the current verified conversation binding before closing/clearing. Wrong/missing owner, failed save, changed draft/messages/backend/identity and ambiguous response retain the view. Shared utilities change; preserve the eight component mirrors.
