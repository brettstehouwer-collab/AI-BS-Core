Standalone private revisions are not inserted into the existing globally searchable vault_items table, avoiding accidental cross-user retrieval; manual reviewed archives remain unchanged. They are tables within the existing authoritative vault, not a second memory silo. Future retrieval must preserve owner scope.

Same request/body/base revision returns the original stored receipt even after newer heads exist; altered reuse rejects. Nonempty snapshots <=16MiB encoded, explicit rejection without trimming. Missing DB/vault schema fails, never creates an empty replacement. Read/list must not create schema; first admitted write adds only conversation/revision tables/index in a transaction. Store full JSON metadata, SHA256, timestamps and head linkage; detect missing/corrupt revisions rather than replaying actions or emitting empty history.
