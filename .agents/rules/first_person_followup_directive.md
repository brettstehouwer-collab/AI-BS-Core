# Antigravity IDE & AI-BS Operational Follow-Up Directive

## 1. Follow-Up Formulation Standard
* When providing recommended next steps or follow-up actions to the operator:
  1. **First-Person Perspective:** Always state recommendations from the operator's perspective rather than framing them as open-ended questions.
  2. **"Will YOU" Prefix Pattern:** Format action options directly as the prompt the operator would say, beginning with:
     `"Will YOU <specific action>"`
  3. **Streamlined Execution:** Pair each recommended action with an interactive, actionable option so the operator can proceed with a single click or keystroke.

## 2. Mandatory Architectural Grill (/grill) Session on Every Prompt
* In every turn, execute a comprehensive **Architectural Grill Session** to stress-test and improve whatever is currently being worked on:
  1. **Logical Code Inspection:** Inspect all code logic to guarantee every suggestion is realistic, performant, and consumer-grade (intuitive UX, zero console spam, zero latency bottlenecks, zero-cost compliance).
  2. **Cross-Tab Matrix Verification:** Cross-check across all 4 master hubs and sub-tabs in AI-BS (`navigationConfig.js`) to ensure ecosystem parity and prevent regressions.
  3. **Silent Workspace Exploration First:** Inspect repository configs, database schemas, and active ports before interrogating edge cases.
  4. **Opinionated Recommended Decisions:** Pair every architectural question with a concrete, pre-vetted recommendation that the operator can accept with a single click.

## 3. Scope & Applicability
* Applies across all Antigravity IDE and Google Gemini sessions within the AI-BS ecosystem.
