# Fire Writing Rule / Post (Immutable Transcription)

**Status:** ACTIVE & IMMUTABLE DIRECTIVE  
**Classification:** Core Communication Standard  

## Trigger Condition
Triggered by unfiltered cognitive streams, journal entries, high-intensity memory recall, or raw input lacking standard sentence delimiters.

## Fidelitas Mandate (Absolute Preservation)
1. **Zero Alterations:** Zero word substitutions, zero spelling corrections, zero vocabulary modernization, and zero grammar smoothing.
2. **Personal Truth Invariance:** The text is ingested as an immutable cognitive transcript reflecting authentic internal cadence.

## Permitted Structural Adjustments
- Insertion of periods, commas, dashes, and question marks strictly to establish logical pauses.
- Insertion of paragraph breaks to delineate shifts in thought.
- Correction of mechanical capitalization (e.g., capitalizing standalone "I" and opening sentence letters).

## Bifurcation Protocol (Strings >400 Characters)
- The raw, unmodified source string must be sequestered inside a Python code block under the variable `raw_source_payload = """..."""`.
- The structured, readable transcription is rendered immediately beneath in Markdown.

## Archival Obligation
Every processed entry concludes with the `stehouwer_reality_archival_block` JSON/Python dictionary documenting timestamp, classification, fidelitas metrics, and core construct mapping.

## Post Add Exceptions (Distribution & Social Formatting)
When raw Fire Writing is adapted for social media deployment, algorithmic reach, or public-facing documentation, the following additions and layout modifications are permitted—provided the source vocabulary remains unedited:
1. **Algorithmic Whitespace & Line Splitting:** Breaking individual clauses into single-line paragraphs and inserting double returns to optimize on-screen dwell time and hit mobile "See More" cutoffs.
2. **Metadata & Tag Block Appending:** Appending categorical hashtags, regional nodes (e.g., `#WestMichiganFilm`), and entity tags at the bottom of the post, isolated by period spacing buffers (`. \n . \n .`) so metadata does not contaminate the reading fold.
3. **Outbound Link Isolation:** Keeping external URLs out of the primary copy body to prevent algorithmic link degradation, restricting conversion links to profile bios or comment-based distribution.
4. **Decoupled Analytical Scaffolding:** Appending external technical breakdowns, clinical trauma mapping, or "Forum Consensus & Empirical Correlation" matrices in completely separate boxes/tables below the post to provide multi-perspective context without altering the author's voice.
